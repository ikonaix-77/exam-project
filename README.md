# 校园机会看板

面向在校学生、尤其是新生的校园活动与机会小产品。无后端、无框架，双击 `index.html` 即可使用。

考核时间背景：**2026年9月19日**。产品只整理题目给出的 26 条模拟信息，不补造未提供的时间、地点、费用或主办方。

## 解决什么问题

校园信息同时来自校级/赛事、学院和学生个人。开放发布能降低门槛，但质量不一：有补充通知、截止已过仍可候补、地点未定，也有加私人微信和商家推广。新生真正需要的是：

1. 今天有什么、什么快截止；
2. 这条适不适合我、要不要报名；
3. 缺了什么信息、该不该信；
4. 自己也能发约球、组队和学习交流，并进入同一套浏览流程。

## 核心功能（可实际操作）

1. **浏览与定位**：今日速览、筛选（学校/学院、学生发布、适合新生、即将截止、需留意）、搜索。
2. **理解信息**：结构化展示时间/地点/对象/参与方式；材料没有的字段明确写成「材料未提供」。
3. **主动操作**：报名/意向登记/候补/标记参加、收藏；结果写入浏览器 `localStorage`，刷新后仍在。
4. **学生发布**：表单发布后进入信息流，可被搜索、筛选、报名和收藏。

## 创新点：信息体检，而不是再堆一个按钮

- **关联通知**：训练营（01）与场地调整（09）、项目招募（03）与名额补充（20）会互相挂上，避免新生只看到过期安排。
- **可信与完整度**：24（私人微信、日结、无主办方）、25（标题交流、正文带购买链接）标为「需留意」，默认可看也可隐藏，且不能当作正规报名。
- **按材料判断状态**：如路演观摩报名已过但允许候补；Git 工作坊「提交报名表 ≠ 录取」；挑战赛「意向登记 ≠ 交作品」。

## 使用

用浏览器打开 `index.html`。推荐先走一遍：今日速览 → 点开一条 → 报名/收藏 → 我要发布 → 刷新查看「我的」。
